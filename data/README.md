# Data

Raw and processed data are not committed to the repository (file size).

1. Download **Online Retail II** from the UCI Machine Learning Repository:
   https://archive.ics.uci.edu/dataset/502/online+retail+ii
2. Unzip and place `online_retail_II.xlsx` in `data/raw/`.
3. Run `python src/01_clean_data.py` to create `data/processed/online_retail_cleaned.csv`.
